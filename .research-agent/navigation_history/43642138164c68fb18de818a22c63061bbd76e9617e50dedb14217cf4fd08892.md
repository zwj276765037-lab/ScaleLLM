### 1. DDR 双通道完全分离

**问题：** DDR0 混合使用，冲突 30% 损失

**收益：** 2.5 → 3.5 tokens/s (+40%)

**问题：** Setup -5.1ns, Hold -3.1ns  
**方案：** Placement + Multicycle + Pipeline（如需）  
**目标：** 100 MHz（Fallback 95 MHz）

## 关键决策点

### Decision 1: 时序收敛判断

```
检查 timing report:
├─ Setup/Hold ≥ 0 → ✅ 继续综合
├─ Setup < -2ns → ⚠️ 实施 Pipeline 插入
├─ Hold < -2ns → ⚠️ 实施同步器优化
└─ 多次失败 → 🔴 Fallback 95 MHz
```

### Decision 2: 分阶段交付

```
如果一周内无法全部完成:
├─ 阶段 1: DDR 分离实现（最小可行）
└─ 阶段 2: 时序修复（下周）
```
