## 阅读时的三个区别

1. **局部误差与累计误差不同。** 局部测试给当前和参考计算相同节点输入；累计测试允许误差沿网络传播。二者不能当成同一个指标。
2. **样本规模和聚合方式不同。** 全量算子表先对每篇文本取跨层/节点最大值，再计算1024篇的分位数；3篇分支对比是合池能量比；TV与Top-1另有逐位置口径。
3. **数值差异不等于任务判错。** Top-1一致率不是ACC，低Margin也不证明语义无损。当前汇总未加入任务ACC或两条路径自由生成后的质量结论。

模型为 Llama-3.1-8B-Instruct，32个解码块，词表大小128,256。全量文本包括网页512篇、新闻256篇、影评256篇。原实验参照保留基础量化、ScaleCode及相关查表/共同出口规则，不能把它称为无量化FP32整模型基线。

各子目录保留完整CSV/JSON及既有Python绘制的PNG。原始运行文件不移动、不覆盖；JSON中的原始来源路径用于追溯。
