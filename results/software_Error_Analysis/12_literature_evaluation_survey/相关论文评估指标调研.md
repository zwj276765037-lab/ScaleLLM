# ScaleLLM：相关论文在 ACC 与数值误差之外的评估

核查日期：2026-10-20。范围：11 篇代表性整数推理、LLM 量化及压缩评估论文。本文依据原论文、官方会议页面和作者公开全文整理；不是穷尽性综述。本次没有新增模型实验。

**结论：PPL 是相近 LLM 量化论文中常见的补充指标；直接支撑“完整回答质量保持”的证据，是配对生成回答评价、生成任务评分及任务正确性翻转。** 对当前已经有 ACC 和局部算子误差的 ScaleLLM，建议新增的主图采用完整回答质量比较，PPL 与现有 TV/Top-1 作为配套证据。

## 2. 三个最值得借鉴的评估

**AWQ 的配对完整回答评价。** 原文图5在 Vicuna 7B/13B 上使用80个问题，并交换答案顺序，共160次裁判判断。它比较量化模型与 FP16 的完整回答，能直接启发我们的新图。该评测应按原协议命名，不能因为都是80题就写成 MT-Bench。[AWQ §5.2](https://proceedings.mlsys.org/paper_files/paper/2024/file/42a452cbafa9dd64e9ba4aa95cc1ef21-Paper-Conference.pdf)

**FlatQuant 的多轮生成质量评价。** 它在 Llama-3.1-8B-Instruct 上使用 MT-Bench，报告写作、角色扮演、推理、数学、代码、抽取、STEM、人文各类别的评分。模型与我们相同，但量化算法和参考模型不同，因此可借鉴评估协议，不能直接比较成绩。[FlatQuant 附录C.2表10](https://arxiv.org/html/2410.09426v3#A3.SS2)

**Accuracy is Not All You Need 的逐题变化评价。** 它的 Flips 是“正确→错误”与“错误→正确”的比例之和，不含“错误→另一错误”。它另用 KL 和 MT-Bench 检查行为变化，指出 ACC/PPL 相近仍可能掩盖变化；也明确翻转不一定造成实际下游退化。[原文§2、§4.3、§6–7](https://proceedings.neurips.cc/paper_files/paper/2024/file/e0e956681b04ac126679e8c7dd706b2e-Paper-Conference.pdf)

## 3. 对我们现有指标的定位

当前已测的 103,700 个固定前缀位置、1,053 次 Top-1 token 翻转，支持的是同前缀单步决策一致性；不能直接填入上述论文的任务正确性 Flips。现有 TV 则衡量32层计算后最终分布的差异。两者都是有用的保真证据，但没有评判自由生成回答的正确性。

另外，上述 NeurIPS 论文的 Top Margin 使用候选答案的概率差，我们现有 Margin 使用全词表前两名的 logit 差。二者可以研究相似机制，阈值与数值不能直接对照。[论文§5](https://proceedings.neurips.cc/paper_files/paper/2024/file/e0e956681b04ac126679e8c7dd706b2e-Paper-Conference.pdf)

现有数据来源：[完整分析报告](../完整分析报告.md)、[逐题数据资格说明](../11_answer_quality_table/输出质量保持数据表.md)。历史 V5 数据不能作为当前舍入版本的质量结论；已完成 ACC 的汇总分数也不能反推逐题翻转。

## 4. 建议新增的一张主图：完整回答质量比较

以下是结合文献提出的本项目实验设计，**尚未运行、尚无新数据**。

图题建议：**Effect of Rounding on Response Quality**

- 图形：一张水平堆叠条形图，每行一个预先确定的任务类别，另加总体一行。
- 三种结果：**Better / Comparable / Worse than Reference**。参考版本与当前版本从同一提示各自自由生成完整回答。
- 图中明确标出 Worse 的比例与样本数；总体结果配置信区间。两轮对话或重复裁判属于同一问题的相关观测，不能当独立题目扩大统计量。
- 评价优先关注正确性、推理有效性、指令遵循与内容完整性。纯措辞差异不能自动判为变差；字符串完全一致率可作辅助诊断。
- 开放回答采用匿名、交换顺序的成对评价，并抽样人工核验；数学、代码或有确定答案的题目优先使用参考答案或执行验证。
- 若采用 MT-Bench，先按公开协议报告可比结果；若要更精确地估计小比例退化，再预先固定更大的独立问题集合和样本量目标，不能从结果中挑选有利样本。

这张图回答：“经过完整自回归生成，当前舍入版本有多少回答被评为更好、相当或更差？”它与现有 ACC、局部算子误差分别对应不同证据。Comparable 是规定评价协议下的判断，不是所有语义和未来任务等价的数学证明。

## 5. 配套表格与最小消融

PPL 建议作为小表补充：在相同留出语料、tokenizer、上下文窗口和计分位置上，报告参考与当前两版本的 PPL，以及

\[
\Delta\mathrm{NLL}
=\frac{1}{T}\sum_{t=1}^{T}
\left[-\log p_{\mathrm{current}}(y_t\mid y_{<t})
+\log p_{\mathrm{ref}}(y_t\mid y_{<t})\right].
\]

这里 \(y_t\) 是语料中的实际下一 token，\(\mathrm{PPL}=\exp(\mathrm{NLL})\)。它衡量模型预测真实文本的平均能力，不能单独证明每个回答质量保持；仍应结合上述完整回答评价。

有逐题正确性时，另报告“参考正确→当前错误”和“参考错误→当前正确”，避免净 ACC 相互抵消。所有分母明确写为总题数或参考正确题数。

针对“多级舍入是否导致质量变化”的因果问题，最小对照建议为：

1. 保留中间精度的参考。
2. 当前正式舍入配置。
3. 最后一层多保留几位的配置，仅在研究该优化时加入。

三者固定基础量化、ScaleCode、LUT、权重、输入、解码设置和评分规则；共同出口的处理要如实记录。比较 FP16 整模型可作为另一个算法总体基线，但不能代替上述隔离舍入影响的对照。

## 6. 文献迁移边界

- I-BERT、Softermax 的质量实验涉及 QAT，不是无训练条件下单独改变舍入。
- Softermax 的面积/功耗来自综合与分析工具；单元或 PE 收益不是整模型实测收益。
- QuaRot 的所引系统图主要是块级；不能与 SpinQuant 的端到端解码延迟混称。
- 4096长度 PPL、显存或首 token 延迟测试，不等于 LongBench 等长上下文任务能力评价。
- 本次没有核实到 QuaRot、SpinQuant、QuIP# 原文提供 MT-Bench/LongBench 结果；AWQ 按其成对评价协议记录。
- MSE、KL、交叉熵若只用于校准优化，应记为优化目标；只有在明确测试集上独立报告，才作为评估结果。
