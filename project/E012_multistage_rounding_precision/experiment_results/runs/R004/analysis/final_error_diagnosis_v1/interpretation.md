# 对整体误差偏大的当前判断

用户于2026-10-19质疑整体输出误差约1.44%是否可接受。本轮只读AT002正式16篇已有数据，CPU分析2.473秒；没有额外模型前向、GPU运行或生产改动。原Q001继续冻结采集，不能因主图局部误差小就宣称整体数值保持。

## 结论与适用范围

整体相对L2误差是实际已存两路输出的差异：6672条比值公式独立重算一致，16篇输入token/位置配对一致，末端参考signal RMS为2.1444–2.2496，排除重复百分比换算和零参考分母。这些检查不等于证明完整实现无任何缺陷。

16篇中位数：第8层0.205666%、第16层0.342659%、第24层0.588243%、第31层0.956574%、第32层1.308994%、最终归一化1.440542%。最后一层相同文档的绝对error RMSE比值中位1.45783，而signal RMS比值中位1.02537；末端norm相对误差比值中位1.08215，15篇升、1篇降。主要跳变发生在最后解码层，不能把问题简单归给末端norm或小分母。

局部与整体复用相同参考算术，但衡量不同对象。精确分解为 C(x_C)-R(x_R)=[C(x_C)-R(x_C)]+[R(x_C)-R(x_R)]。同输入局部测量只覆盖第一项；完整路径还含第二项及下游动态量化变化。此恒等式解释为什么局部小不构成整体小的证明，不给出当前主因或数值上界。两项之间存在交叉项，不能直接相加相对L2百分数或以32倍局部最大值作为实测归因。

实现只读核查未发现已确认的首末层接线/Down05符号错误；已记录sat/overflow/format异常计数为0。Linear/QK/PV逐组floor方向偏差由源码确认，动态量化码变化由审计数组确认，但尚无干预实验可把1.44%归因于其中任一项。

预定审计文本N=1还显示：第2层reference信号能量99.8784%集中于首token，整段相对误差0.03702%，同文本逐token误差中位数却为1.0194%。因此早期整段范数比的下降不能当误差消失；它含信号权重改变。最终误差没有同样的单token能量主导：最大token误差份额2.624%，该文本最终逐token误差P50/P95为1.3346%/2.2609%。这些token仅作一篇文本内描述，不能作为独立文档扩大N，也不能由此断言其他文档或局部五类具有同样集中现象。

## 下一项可区分实验（尚未运行）

1. 固定预定审计文本及其已存第31层出口，构成两种入口（当前轨迹/参考轨迹）×两种算术（当前/保留中间精度）的第32层2×2回放；固定模型、权重、共同量化规则和出口，四路均各自按相同算法重算动态码。
2. 保存attention输出、第一残差、post-attention norm、MLP各投影/门控/Down整数出口、Host解码、第二残差。使用误差向量和能量及交叉项分解，不直接叠加百分比。
3. 在同一入口下逐个干预六个额外舍入开关，并明确交互项。强制锁动态码只可作为另列的条件诊断，不能替换主自由传播结果；改变floor规则/小数位数先作为候选，不直接替换已验证生产版本。
4. 加入每token数值误差分布，仍以文档作为统计单位。只有实际数据能确定需要修实现、改哪处舍入或增加哪些小数位；目前不能宣布1.44%可接受或精度保持通过。

模型回放尚未登记/执行。本轮没有修改Q001预算、源、输入、输出指标或自动图；后续模型诊断须独立身份及有限资源合同，避免与当前GPU队列争用。
