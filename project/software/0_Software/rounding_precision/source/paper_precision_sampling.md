## 1. 要证明的三个层级与真正的样本量

| 层级 | 比较与结论 | 独立统计单位 |
|---|---|---|
| 局部误差机制 | 固定同一整数码/metadata/近似函数，测额外中间舍入；精确oracle核查 | 文档/原始prompt是抽样cluster；其内层、token、通道、点积组均相关 |
| 传播 | 同一输入文本，两条完整轨迹逐层演化，比较hidden/logits；基础量化与权重制品相同 | 文档；所有窗口和层共同保留在同一cluster |
| 任务非劣效 | 配对NLL/PPL、官方任务正确率，给差值CI并对预设容忍量检验 | 独立任务item；共用passage、问题改写/代码变体按原始item聚类 |

`N_documents`、`N_items`、`N_tokens`、`N_tensors`、`N_scalars`、`N_groups`必须分列。一个prompt的58,368个组不是58,368个独立样本；旧32/128来自同文本且共享前缀，不是336个独立样本。重复seed/重复确定性运行也不增加文档数。随机生成多次时以prompt为cluster，另估seed方差。

局部阶段固定两分支相同输入码；传播阶段激活码可以因前层舍入而改变，这是被测传播的一部分，不能逐层强行重置相同码。两阶段不能互相替代。仅比较BF16/QDQ与当前实现的差值包含基础量化/近似误差，不能全部归因为中间舍入。

## 3. 可立即写入主协议的覆盖起点

**机制分析计划起点：至少1,024个去重文档、至少3域、全部32层。** 候选分配C4 web 512、AG News 256、IMDB 256；域主汇总等权，各域内部文档等权。此分配只是采样/资源起点，不保证任一CI精度或非劣效功效。只有source/去重/曝光审计确认可用独立cluster足够才冻结；否则先报告实际缺口，不用重复段落补足。

- 固定一个master seed，用`hash(seed,dataset_revision,document_id)`排序抽样，无人工挑文；长度、域等预先分层，公布每层frame数/抽中数/纳入概率。短文档不因“凑长序列”被静默丢弃，不足长度计入短长度层并保存mask/实际token数。
- 所有文档覆盖32层×7 Linear（Q/K/V/O、Gate/Up/Down）；GPU尽量对每个实际token、全部输出通道流式聚合误差/信号能量，不落全tensor。完整组数128/448与全部lane用于任何被审计的Linear输出；不能只留易算的组或裁掉负贡献。
- 精确oracle分层审计子集起点：64文档，覆盖3域、长度层及极值层；每层每Linear随机4个token（首/中/末及区间内随机，短文档按实际支持）、4个输出通道。通道先按位置分4等大箱再各均匀抽1，种子包含doc/layer/op，跨两分支固定；不能一直只用0/1/63/last。主覆盖与审计子集分别记分母，不宣称所有流式输出均逐条任意精度验证。
- 若主流式聚合受限而必须抽样，先按位置/长度箱均匀抽token、按等宽输出通道箱抽样，记录纳入概率；总体信号/误差能量用相应加权总和之比估计。不得把低概率极值过采样直接混入普通均值。另设预定义stress集合（极值/近零/长上下文），单独报告。
- 不只测Linear：每层登记RoPE(Q/K)、QK恢复/clip、Softmax、PV恢复、SiLU×Up/SwiGLU及residual/层输出。RoPE保留成对坐标；QK保留完整head维贡献；Softmax/PV保留被测query的全部合法causal keys、mask及归一化，不能随机删key再称原算子。其他节点须由A014逐项冻结输入、近似函数、舍入出口、位宽/异常及独立参考后执行，不能套用Linear界。
- 按节点保存合法、shift/溢出/饱和、clip、非有限、跳过等计数和所有有效分母。异常不从全模型任务分母中无声消失；数值非法须先定位/新版本复验，不能靠丢样宣称精度保持。

**长度是两个协议域：** 硬件对应`hardware_128`保持原128限制及全部格式/缓存约束；软件长序列512/2048另列，需先核新长度的KV/PV/QK位宽和可执行协议，不能仅改max_length后称硬件已支持。两域使用各自mask、计分token与结果。128上通过不能证明长序列；软件长序列通过也不证明现有硬件支持。

若论文只主张Llama-3.1-8B，只能写该模型。若主张架构/模型泛化，预注册多个实际架构/规模/模型家族；每个模型匹配自己的层数、GQA、tokenizer和量化制品，不能把Llama的32层模板强套其他模型。现有“六模型”历史分数不构成新舍入开关的多模型证据；模型seed不是随机抽样的模型总体。

## 4. 主指标与CI

对文档d、层l、节点s，保存共同输出参考能量`S=Σ y_output_only²`及额外误差能量`E=Σ(y_current−y_output_only)²`，主报`relative_L2=sqrt(E/S)`（或NMSE=E/S，必须标是否开方）。近零/零信号另列绝对误差及零信号比例，不靠随意加epsilon隐藏分母问题。局部可同时对精确oracle给同样指标；基础量化对BF16误差仅作另列背景。

同时给文档等权分布（中位/P90、必要时P99）与明确能量权重的micro比值，不能互换。CI以**文档为块成对重采样**，同一文档的全部层/token/窗口/通道一起移动；域分层保留预设权重。预先规定10,000次bootstrap/seed和Monte Carlo稳定性检查。若声称“所有层均小”，用文档bootstrap的max-statistic同步带或显式多重校正，不能把224个点的95%逐点CI当整体95%。P99仅在文档数足够时给区间，不能借百万相关scalar制造窄CI。

NLL主量为同一teacher-forced token/mask上的`Δ_NLL=Σ_d U_d / Σ_d T_d`，`U_d=L_current,d−L_reference,d`，每个token只计分一次；重叠窗口只增context，不能重复算scoring token。完整文档所有窗口同cluster。配对document bootstrap每次重新算这个ratio，然后转为`PPL_current/PPL_reference=exp(Δ_NLL)`。不得bootstrap单token或对各窗口PPL简单平均。额外给文档宏平均作敏感性分析，不替换主token加权估计。

## 5. 功效、可接受差值与正式任务

**容忍量不是从本轮结果倒推。** Root须在正式test前记录论文目标及依据：允许正确率损失`ε_ACC`、允许相对PPL增加`r_PPL`（对应`ε_NLL=ln(1+r_PPL)`）、主任务/域、α及多重性家族。依据应为可接受应用损失/已发表比较尺度/作者明确论文声明，不能以“当前差值刚好过线”或普通test不显著代替非劣效。下表的0.2/0.5/1.0pp及0.1/0.5%均为**规划例，不是已批准阈值**。

配对正确率令`D_i=correct_current−correct_output_only∈{-1,0,1}`，`δ=E[D]`，`q=P(D≠0)`；直接有`Var(D)=q−δ²`。独立item的95%近似CI半宽`1.96 sqrt((q−δ²)/N)`。Root最终整合口径：主非劣效采用双侧95%区间下限大于`−ε_ACC`（单侧α=0.025）；真差δ=0、80%power时粗略规划`N≈(1.9600+0.8416)² q/ε_ACC²`。以下计算使用正态分位数的完整精度，不把两种置信口径混用。最终用预注册、已数值验证的配对score/profile-likelihood CI；小discordance不用普通Wald或“不显著=等价”。[Newcombe 1998](https://onlinelibrary.wiley.com/doi/10.1002/%28SICI%291097-0258%2819981130%2917%3A22%3C2635%3A%3AAID-SIM954%3E3.0.CO%3B2-C)

| 假设q | ε=0.2pp所需N | ε=0.5pp所需N | ε=1.0pp所需N |
|---|---:|---:|---:|
| 0.02 | 39,245 | 6,280 | 1,570 |
| 0.05 | 98,111 | 15,698 | 3,925 |
| 0.10 | 196,222 | 31,396 | 7,849 |

这些近似未加多重校正、聚类或域漂移代价，q来自**独立development**或保守预设网格，不取正式test后挑较小值。q=0观测不能当真实方差=0；例如N个独立item均无不一致时，97.5%单侧上界仍为`q_U=1−0.025^(1/N)`，不是0。共passage/变体时改用cluster方法并报告cluster数，表中item独立公式不能照搬。

例如假设q=0.05，GSM8K完整1,319题的近似95%半宽仍约1.207pp；HellaSwag10,042题约0.437pp。这是规划情景，不是实际CI或“不可能通过”的断言。正式任务尽量完整官方test，按实际可达精度诚实给区间；不能生成题目改写、重复采样benchmark或把不同任务乱合并来凑N。区间跨margin则结论不确定，不宣布精度等价。若主张每个任务非劣效，逐任务检验并预设多重性；一个合并均值不能掩盖失败任务。

NLL的cluster ratio近似标准误为`SE²≈[D/(D−1)] Σ_d (U_d−Δ_hat T_d)² /(Σ_d T_d)²`。令development估计的有效文档标准差为`σ_eff`，则真Δ=0的80%power规划为`D≈7.8489 σ_eff²/ε_NLL²`，最终仍用成对document CI。例：允许相对PPL增加0.5%时，σ_eff=0.02/0.05/0.10对应约127/789/3,156文档；若只许0.1%，则约3,143/19,642/78,568文档。**σ_eff尚未测，1,024不是充分保证。** 数据不够时报告宽CI或缩窄论文声明，不从正式test反复加样直到过线。

开发pilot只估方差/不一致率与资源，不选择正式容忍量；最终N、最大样本量和停止规则在test前冻结。若分阶段查看test，必须另预注册有效的序贯CI/α花费；默认固定N，不提供随时窥看后停止的显著性结论。生成任务配对prompt/解码策略/seed/评分器固定，失败/截断/停止条件一致登记；不能只比较两分支恰好生成相同答案的题。

## 7. 资源与分阶段执行建议（均未执行）

保留CPU总4线程、单worker≤2线程/8GiB RSS，GPU0单worker≤24GiB、共享free≥8GiB，起跑free≥30GiB/RAM≥32GiB；GPU1/EDA排除。任何新阶段先≤300秒pilot；CPU单次≤20分钟，原256MiB单AT证据上限不自行放宽。一次GPU只放一份模型/权重，两分支串行或共享已冻结权重逐层计算、各自状态分开；不同时复制两套8B模型。不把128-token BF16约14.44GiB峰值当成长序列/V5宽参考也必然可装的证明。

| 设计量 | 可核算估计及含义 |
|---|---|
| 1,024文档×32层×7 Linear×8token×16channel（若逐标量采样） | 29,360,128输出、约51.0亿完整group；**独立文档仍仅1,024** |
| 每group只存dot int32+四个u8 metadata | 仅此已约38GiB；去重qa另约9.5GiB，尚无零点/索引/权重/非Linear；不应巨型JSON落盘 |
| GPU流式主统计 | 例每doc×32层×10节点×128B的moments/count约40MiB总量；各长度/域另计。只存每文档统计、异常/极值和有界抽样，不常驻全部hidden |
| 64文档、32层、4token、4channel的Linear精确审计 | 229,376标量；紧凑group约304MiB，qa约304MiB，固定4行权重panel约4.75MiB，metadata/其他节点另计；可拆小AT而非突破256MiB |

上述存储按Llama维度算，非实际测量/磁盘配额；随机通道panel变化时权重缓存/索引另算，不能套固定panel下界。流式覆盖可全token/全通道，精确审计按子集保留完整组，二者证据范围分别声明。

现有约45秒成本主要含15GB模型加载/消费身份hash，不能乘1,024当总耗时，也不能推断成对V5的单文档速度。成本模型应为`单次加载 + Σ文档(当前+仅输出+流式统计) + 精确审计 + CI计算 + IO`；新节点、序列长度、显存峰值必须实测。每个AT记录t_load/t_current/t_output_only/t_capture/t_oracle/t_IO与实际文档数，超限保留失败/缩小batch，不提高预算。

建议顺序：A. 只读ID/边界/去重/曝光与预注册清单；B. train-only development小pilot验证两条真实完整轨迹、全部节点合同、方差和资源；C. 冻结目标margin/N/CI/多重性后，以文档分块执行≥1,024起点的机制覆盖与分层精确审计；D. 完整官方任务配对评估，给真实CI；E. 需要更广声明时新增预注册模型/域。主统计与审计每AT只装可容纳小batch；不因已有工具创建成功就跳过完整轨迹数值资格。

## 8. 结论边界与参考

当前168标量单prompt只能支持数值工具与该输入的局部机制，不能证明模型总体精度；新1024计划同样不自动保证功效、跨模型泛化或顶会结论。统计CI不替代生产一致性/异常覆盖；确定性Linear界也不限制深层非线性传播。完整官方test的区间若不足以支持预先声明，必须保留“不确定”。SM023还需真实实现与同协议端到端结果，不能由此设计文档代替。

统计依据以本文件显式推导为准；配对重采样与假设检查参考 [Dror et al., ACL 2018](https://aclanthology.org/P18-1128/)、[Koehn, EMNLP 2004](https://aclanthology.org/W04-3250/)；选择文档而非token为块是本研究对依赖结构的设计决定。配对二元差CI参考上引Newcombe，最终实现须通过边界/覆盖检查；这些论文不为本项目指定容忍量、文档数或证明外部泛化。
