execution：基于已审报告与 Root 提供的当前设计约束完成架构评判，未重新审核终态、启动 EDA、读取 DCP 或修改生产。verdict：联合包有条件可行，必须先闭合下列语义与物理未知；review：本记录不是对尚不存在的实现或约束坐标的批准。

**parent_head：实际连接必须改变，FIFO 必须保留。** 每个 bit 在综合网表中本来就是独立对象，单纯把宽变量拆成多个变量不必然改变任何驱动/负载。可纳入本包的是：依据实际消费字段切分本地数据/选择逻辑；确有远隔多消费者时，在原捕获沿由同一个输入 D、CE、reset 更新最少量的局部副本，并让相应消费者只用本地副本。不要给每个 branch 无差别复制全宽 head。现有 FIFO 用于隔离 remote-ready 时序，应保持其缓冲、反压与入出队语义，不能为省面积删掉或形成新的 remote-ready 组合回路。新增副本可能增大 FIFO 输出/输入 D、CE/reset、时钟负载，必须算清新增位数与扇出迁移，而不是只计算下游减掉的扇出。

**meta 地址：复制同拍状态，不能串联寄存。** 若原状态满足 `A(t+1) = CE(t) ? next_addr(t) : A(t)`，本地副本须采用同一更新方程、时钟、复位方式/值、控制优先级和位宽；每个 URAM 采样沿都应满足 `A_local(t) = A(t)`。`A_local <= A` 会把地址延迟一拍，不能当作等价替换。URAM 读 enable、read latency、地址拼接与读写冲突语义也保持。副本只应按已确认的实际消费簇建立，并在允许的物理区域靠近那些 URAM；RTL 中叫“local”不证明物理位置已本地化。若拿不到原地址状态的完整 D/CE/reset 更新逻辑，或无法证明采样沿一致，就不能把新增地址寄存器列为本包确定改动。

**约束：明确作用对象，暂不能臆定坐标。** 初始 SLL 表格顺序尚未映射到物理 X 列，也没有完整最终跨边界端点集合；top10 是样本。三 SLR occupied CLB 很高，但这不说明哪些兼容 LUT/FF 槽还能容纳副本。因而当前不能据此直接写新的精确 LOC/BEL、强制某分支进 SLR0/2、Pblock 边界/大小、横移若干列或 SLL 分流坐标。可纳入的是经核实对象限定的约束和验证脚本；固定坐标必须有硬块位置、消费端范围、时钟区、可用兼容资源与拥塞证据支撑。不要用广泛 DONT_TOUCH 强留所有副本；只在证明需要、且不破坏已有保护的对象上防止不应发生的合并。现 C01/全局接口/验收的改变应由 Root 在联合包内明确记录，不能混在普通 bank 重命名里。
