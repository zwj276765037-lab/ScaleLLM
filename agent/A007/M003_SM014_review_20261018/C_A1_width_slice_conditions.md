# C-A1 同深度宽度分片：G2比较条件

2026-10-18；A007。Root已将“同深度width-sliced存储＋同沿地址副本”列为比较候选，**尚未选入、未定粒度**；候选表由Root维护。这份记录给出可实施的语义形式及物理证据依赖，不代表已取得新URAM映射/性能证明。

## 与当前结构的真实差别

现resident只有一个256bit数组和一个read index。宽度分片需把逻辑字宽拆成不重叠且完整覆盖`[255:0]`的各片，每片深度仍81920；每片的读表达式实际使用分配给该片的同沿地址副本。不同地址Q因此有明确且可在新网表查验的存储读者。所有片的响应数据直接按原bit顺序拼接，不增加深度bank选择器或256bit返回mux。

若两片最终仍被综合合成同一个共享地址源，强机制没有实现，即使功能相同也不能记结构PASS；保留副本的属性/层次/物理方法须在G2限定，G4实核所有实际URAM地址pin的driver和所属片。不能只检查counter数量。

## 必须保持的单控制器语义

建议设计表达保留原单一控制器和所有外部端口/握手。公共`wr_fire`驱动全部片，同一`wr_addr`写原数据切片；公共`rd_fire`驱动全部片，各自使用其同沿地址；各片响应寄存器同沿更新并直接拼接。原`rd_port_open_r`、`rsp_valid_r`、read/write/format/error计数和单pending语义只存在一份，不能未经论证实例化多个完整resident模块再拼接结果。

1. **读写采样：** 原RTL同沿write/read用非阻塞赋值，读采样旧存储值；每片保持这一关系。合法的全字读写不应变成某片新值、某片旧值。旧RTL语义必须保持，URAM实际read-during-write模式及级联/输出寄存器在新综合中另核。
2. **响应：** response valid、返回沿、数据拼接、stall保持和非旁路request token不变。不能为改善级联而增加可观察输出周期；数据无效时不额外要求清零。
3. **地址等价：** core原counter继续服务tile/group标签与范围判断。设`S=system_clear`、`L=(state==ST_LAUNCH && weight_command_ready)`、`R=meta_rsp_fire`，reset之外的原next-state为`S?0:(R?old+1:(L?0:old))`。这是原launch赋值在前、rsp赋值在后的NBA顺序，不是launch优先。每个局部副本要么执行相同递推、要么使用经过证明等价的同沿D；`local<=original`不合格。async reset一致，含abort的datapath_clear不能替换S。
4. **范围/非法输入：** 原wr_ready、rd_ready的地址合法性判断和错误计数保持同一口径；片内索引不能仅截位而把非法地址映射到合法条目。局部副本与原地址在有效采样沿相等的证明不得假定新的ready行为。
5. **控制成本：** 公共rd_fire/wr_fire/clear/token不因分片自动变本地。地址独立递增器意味着额外carry/LUT/FF和控制负载；若广播共享next_addr，则长线可能转到副本D端。两种实现的F3必须分清，不能只预算17×副本数FF。

## 容量估算与实际物理资格分开

不能只用总容量81920×256不变推断URAM块数不变。以单块名义4096×72配置作**算术估算**，每片宽`w_i`时块数参考为`20 × Σ ceil(w_i/72)`，其中`Σw_i=256`。例如2×128或4×64按此算术各为80块，8×32为160块；这些仅说明取整代价，**不是粒度建议，也不是当前或新图实际配置证据**。输出宽度、配置/级联模式、工具推断和实际布局必须由报告核实。

A006正在提取既有80URAM实际位置、消费位和已导属性。若CASCADE相关字段、列/级联边或实际数据位映射不在冻结导出，必须NOT_MEASURED；不能从名字中的index或URAM数量反推出cascade。G2应给物理局部化可检验机制及兼容资源依据；新图精确对象/URAM映射/保留副本/地址pin来源/延迟资格留G4关闭。源码注释中“SLR2 metadata pblock”不是当前物理位置证明，使用原生site/SLR记录。

## 比较时的判据

单memory-side副本只隔离core标签和内存读者，成本较小但仍有全memory地址分发；宽度分片有真实多读者集合和无返回深度mux的结构机会，但增加地址状态/逻辑/控制负载并可能改变URAM打包。C-A2深度银行另有高位bank选择及宽响应汇聚成本。三者应基于真实读者簇、完整D/Q/控制成本和可验证物理实现比较，不能默认全部叠加。

只有明确了具体片划分/副本数、原/新连接、更新方程、预算、保留/放置策略和反证条件，才能形成可审核G2方案。当前仍是准备，等待真实子表和工程建议。
