# Final Decode16 bitstream

`ScaleLLM_Final_Decode16_80MHz.bit` is the original reader011 artifact:
80,159,263 bytes, SHA256
`96df1a5c1bf4174921bc02ccd88df4066dece3d62b491acb3106bb90ac0ffc85`.
It targets VCU118 / `xcvu9p-flga2104-2L-e`, with 80 MHz core and 200 MHz DDR UI
clocks, and was generated by Vivado 2025.2.

[Artifact identity](final_decode16_manifest.json) records the final timing,
routing, DRC counts and source checkpoint SHA. The checkpoint is not required
for the [portable source build](../docs/BUILD_HARDWARE.md). Board validation and
performance are documented in [the results](../docs/PERFORMANCE_AND_RESOURCES.md).
The older prefill bitstream remains in repository history.
