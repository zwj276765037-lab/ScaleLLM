# 多级位宽舍入：论文证据协议 v2

2026-10-19；Root依据用户“统计数量不足、LSB无法说明精度、需要顶会级清晰证明”的纠正重建。状态：设计与证明审查，不是正式大样本结果。E012已完成pilot原样保留，整体精度保持命题仍待验证。

## 1. 论文必须准确回答的命题

在指定模型、输入分布和硬件数值协议下，额外中间舍入造成的数值扰动是否在预先规定的误差预算内，是否经过全模型传播仍使任务质量满足预先规定的非劣效限值。不能把“没有溢出”“不超过一个最低有效位”“输出相同占比”单独写成精度保持。数学上完全无损已被合成反例排除；经验上的可接受精度退化必须指定范围和预算。

## 2. 对照与因果隔离

局部：两路径固定完全相同的输入整数码、权重码、ScaleCode、组顺序及共同输出接口，精确有理数为第三方参考。当前实现相对“仅在算子出口舍入”的差才隔离所覆盖的额外中间截断。

端到端：主对照改为明确可实现的“保留基础量化的宽算术参考”和“当前位宽实现”。冻结权重量化制品、基础激活量化规则、Hadamard、近似函数/LUT、mask、tokenizer、位置和cache协议；每条轨迹根据自己的激活重新生成动态量化码，禁止强迫两条整网轨迹共享激活码而隐藏传播。节点级对照合同必须枚举哪些舍入可取消、哪些是算法本身必要量化/函数定义。不得同时替换近似函数为真实数学函数而归因纯舍入。

BF16原模型仅作基础量化损失的上下文基线，不能用BF16与当前实现的差直接表示额外舍入损失。三条基线用语义名称，不使用R1/R2/R3。

## 3. 数学证据：局部确定性界与传播条件

对已核Linear恢复，设y*是相同量化码的精确实数结果，G_right为实际需要右移的贡献组数。每次算术右移相当于向下取整，丢失非负余数；将丢失量换回实数单位相加得到D。合法shift、raw/guard/每步acc无越界、输出无饱和时，

    y_current = Q16(y* - D)
    0 <= D <= G_right * 2^-24
    |y_current - y*| <= D + 2^-17

Q16指舍入到小数16位的固定网格，恰半时离零（half-away），非FP16。该式止于整数出口解码的精确实值；Down随后int32转Host FP32的额外丢位必须另计，不能把此界直接当作Host张量界。证明直接来自floor(u)=u−fraction(u)及末端最近舍入误差不超过半个输出步长；无需独立噪声或零均值假设。D可从整数余数精确复算。仅输出舍入为Q16(y*)，当前−仅输出舍入之差非正且绝对值不超过D+2^-16；当前−精确结果的末端误差可正可负。各输出的确定性界与同码率是附录级实现验证，不代替下面的相对精度和任务实验。

这一证明不依赖抽样，却有明确适用域。信号接近零或组间强抵消时，相对误差可很大。QK/PV/RoPE/RMSNorm/softmax/SwiGLU及量化阈值跳变须单独定理或性质，不套Linear公式。逐层传播界只能采用实际可证的放大系数/阈值条件；不能假设整网1-Lipschitz或误差按sqrt(G)增长。严格界若过松必须报告，不能把经验局部Jacobian当全域证明。

输出联系：在同一输入上下文、同一目标token及相同评分mask且logits有限时，若两套logits的无穷范数差<=epsilon，则单token交叉熵变化绝对值<=2epsilon；参考最大logit与次大logit间距>2epsilon时top1不变。这是条件证书，不保证所有token条件成立，不等于自由生成任务准确率不变。多选题须对实际答案score的误差界和margin做对应分析。

## 4. 数值精度的主要测量

每个文档/层/算子先记录相同形状输出张量，主要量为

    relative_L2 = ||Y_current - Y_reference||_F / ||Y_reference||_F

它回答“舍入误差是信号幅度的多少”。同报绝对RMSE、归一化有符号偏差、文档级中位数/P95/P99及最大值；零范数张量另列绝对误差，不用任意epsilon掩盖。按层/算子/通道和信号强度分层，防止少量大幅度分量掩盖小信号。SQNR可作为等价的dB展示，余弦相似度只能辅助。

两类实验都必要：①同输入单节点注入，定位本地误差；②两个完整模型从同一token输入独立前向，逐层记录真实传播后的隐藏状态和logits误差。另做节点类别消融、层深累计打开的诊断实验；后者不能替代独立全链对照。任何溢出/饱和/非法值单列比例并保留原始反例，不能从主结果静默删除。

## 5. 规模、数据与统计单位

机制研究的计划起点为至少1024个去重独立文档、至少3个数据域、全部32层、所有实际舍入节点；该数字是覆盖计划，不是统计充分性证明。具体可行性、域配额、原document IDs、切分、种子、窗口和通道策略由采样方案冻结。分辨率和资源不允许全量精确逐标量回放时，GPU流式汇总全部输出的误差统计，另对预先分层抽取子集做任意精度核验；不写数十亿组JSON记录。

独立单位是文档/题目。同一文档的token、通道、窗口和多层观测是相关重复测量，必须按原文档聚类统计；百万标量不等于百万独立样本。原first64/first128混合来源只作工程smoke，不能用于正式校准/冻结容差/估计盲测统计功效；正式样本需要独立划分、恢复ID与去重。

所有方案首先遵守实际hardware_128输入协议。若另测长上下文，必须显式标为软件扩展，三对照统一序列长度/mask/position/cache/评分token；不能把128与2048协议PPL相减。论文只覆盖单模型时限于该模型；若声称跨模型通用性，需另选结构/尺度并说明依据，不能由单个8B外推。

## 6. 任务精度的非劣效检验

先冻结有依据的允许退化delta_NLL和delta_ACC，再对同一题目/文档做成对比较。任务表显示基线、当前值、成对差值及置信区间，而不是只显示两条接近的柱。统一规划口径：报告双侧95%置信区间；DeltaNLL=当前−参考的区间上限<delta_NLL，DeltaACC=当前−参考的区间下限>−delta_ACC。这对应单个非劣效检验单侧alpha=0.025，最终再按预先定义的多重性家族调整。多个主要任务需预先定义同时结论和多重性处理。未显著差异不等于等效/非劣。

NLL主估计为全部文档loss差之和除以全部唯一scoring token数；按原文档聚类重采样，每次重新计算这一比值，不能与文档等权NLL平均混用。PPL_ratio=exp(DeltaNLL)，相应区间单调变换。准确率采用题目级paired correctness差，不用两个独立比例近似丢掉配对。设两路径正确/错误结局不一致概率为q，差为Delta，则近似Var(d)=q−Delta^2。样本数必须由开发数据估计该方差和预定delta/功效推算；q是正确性不一致率，不是任意输出文本不一致率。观测q=0不等于真实方差为0；正式CI须预先冻结并验证paired score/profile方法，或按依赖结构采用适当cluster方法，小discordance不能用退化Wald给零宽度区间。

仅作规划示例：若q=5%、n=10000，接近零退化时双侧95%区间半宽约0.44个百分点。因此“有一万题”也不自动足以支持0.1或0.2个百分点内退化。既定benchmark不足以支撑严格界时，如实报告不确定，不能通过复制题目/改bootstrap seed增加有效样本。正式任务尽量完整官方测试集，GSM8K生成协议单列，不与似然评分混为同一平均值。
