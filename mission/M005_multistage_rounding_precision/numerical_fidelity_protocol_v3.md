# M005 数值保真执行协议 v3

2026-10-19，用户确认要证明多次位宽舍入保持数值精度，方法ACC已完成。此协议取代v2中NLL/PPL/ACC及任务非劣效的范围；已有结果保持。当前是执行协议，不是已获得精度保持结论。

## 要回答的命题

在规定ScaleCode格式及合法数值域内，每个额外截断/舍入点带来的误差是否满足可证明的界；这些误差相对真实信号有多大；经过模型32层后是否明显累积。全输入域的数学界、真实输入上的分布、32层实测传播分别提供证据，不能相互替代。

## 对照与归因

两路使用相同权重整数码、基础量化算法、ScaleCode解码、LUT/函数近似、节点出口和Host转换。局部实验固定完全相同输入码。参考用精确整数/有理数保留中间信息，最后执行共同出口规则；当前路径逐处复现生产截断、wrap及饱和。额外报告未经出口舍入的精确节点值，避免共同误差被抵消。Host转换单列诊断。

自由传播时两路使用相同原始文档和冻结权重，各自根据本路激活重新生成动态码；保留这些编码变化作为误差传播的真实部分。不把BF16与量化实现差值归因为中间舍入，不把旧QDQ作为该参考，不修改生产实现。

节点包括Linear、RoPE、QK、Softmax插值和归一化、PV；SwiGLU及Host共同出口单列。各节点采用其实际数值规则，不能把Linear界推广到所有算子。参数必须逐字段符合format05，包括Down S32/shift12/S45/S54。

## 可读的数值指标

对一文档某层/算子的参考向量 r 与当前向量 c，主指标为 `100 * ||c-r||₂ / ||r||₂`（%）。0.01%表示误差向量的长度为参考信号长度的万分之一，不是模型ACC差值。相对误差按文档、层和节点分别计算，不能只用全模型能量加权汇总掩盖低能量节点。

同时记录归一化有符号偏差 `100 * mean(c-r) / RMS(r)`、绝对RMSE和最大绝对误差。对独立文档的指标报告P50/P95/P99及文档级置信区间；最大值只代表已观察范围。零参考能量独立分类，小信号区间保留绝对误差，禁止偷偷加epsilon得到漂亮相对数值。有限文档下P99统计不确定性需明示。理论界适用/不适用、溢出、饱和和非法shift均有计数及有效分母。

正式数值结果产生前冻结主图的文档级统计量：每篇文档、每类节点先在全部32层及其调用位置取最大误差，再对文档报告分位；另报跨全部五类节点的总最大值。严谨定义为使全部所需位置满足 `||c-r||₂ <= (M/100)||r||₂` 的最小非负系数M。双方信号/误差均为零时保留原局部ratio=null并单列exact_zero_match，该位置不增加约束；参考能量为零但误差非零时M为无穷并保留该文档；缺失/非法记录令M不可估，不能静默过滤后取其余最大。对该单一文档统计量的分位区间无需再对内部32层重复校正，但跨节点类别、来源域、分位或逐层传播的联合声明须另列比较族。固定来源配额的合池分位仅作描述性统计，不能冒充同分布独立文档的置信保证。

不将LSB作为主图单位。需要解释硬件量化格点时，称“输出最小刻度”并给真实值；S*.16固定小数位的刻度为2^-16，并非IEEE FP16。
